# CAD 工具箱

输入 `THBH` 后选择“图层”或“占位符”方式，再框选图纸区域进行连续编号。插件只处理普通 `TEXT`、`MTEXT`，不依赖图框属性。

工具箱还包含“批量做图块”：将选中的散图按聚簇距离自动分组，每组创建一个独立图块，块名按 `前缀-001` 连续生成。

## 推荐的图框设置

图层方式：在每张图的图号位置放置普通文字，并让这些文字使用同一个单独图层。

占位符方式：在普通单行文字或多行文字中填写 `{{图号}}`，例如 `图号：{{图号}}`。

插件首次替换后会在对象上保存原始模板，因此后续仍可反复框选并改号。

不使用占位符时，先运行 `THCS`，点选图号位置的一个普通 `TEXT` 或 `MTEXT`。插件会记住它的图层，以后执行 `THBH` 时，框选范围内这个图层上的普通文字会依次改为 `DB-1`、`DB-2` 等图号。

## 命令

- `TYPC`：打开可停靠的 CAD 工具箱；`TYY`、`THUI` 作为兼容命令保留；
- `THBH`：框选图纸范围，输入新的图号并替换；
- `THSZ`：修改占位符，默认是 `{{图号}}`；
- `THCS`：点选一个普通图号文字，指定其所在图层为图号图层；
- `BBLK`、`BATCHBLOCK`：按聚簇距离自动分堆并批量创建图块；
- `WZXX`：快速创建文字线型；
- `TAXX`：快速创建图案线型；
- `IFX_DRAWINGNO`、`IFX_DRAWINGNO_SETTINGS`：对应的英文命令名。

## 批量做图块

运行 `BBLK` 后依次选择对象、输入聚簇距离和块名前缀，并选择基点方式与原对象处理方式。

- 聚簇距离：对象包围盒间隙不大于该值时归入同一组；
- 基点：可选每组包围盒左下角或中心；
- 转成块：删除原散图并在原位置插入块参照；
- 仅建块定义：保留原散图，只在图块表中创建定义；
- 含锁定图层对象的组在“转成块”模式下会被跳过。

## 快速制作线型

`WZXX` 创建文字线型，可设置线型名称、显示文字、文字高度、线段长度和间距。

`TAXX` 创建图案线型，可选择圆点、方框、轨道或保温棉图案，并设置图案缩放、线段长度和间距。创建后可将新线型应用到所选对象、设为当前线型或仅创建定义。

## 使用方法

1. 在每张图的图号位置放一个普通文字，并让这些文字使用单独的图层。
2. 首次使用时输入 `THCS`，点选其中一个图号文字来指定图层。
3. 输入 `THBH`，选择“图层(L)”或“占位符(P)”。
4. 选择占位符方式时，输入占位符名称；回车沿用上次名称。
5. 指定包含多张图纸的范围，输入起始图号，例如 `JZ-01`，然后选择编号方向。

框选多张图并输入 `DB-1` 时，将依次生成 `DB-1`、`DB-2`、`DB-3`。输入 `DB-01` 时会保留补零格式，生成 `DB-01`、`DB-02`、`DB-03`。

- `L`：从左到右，先排完最上面第一行，再排第二行；
- `R`：从右到左，先排完最上面第一行，再排第二行；
- `T`：从上到下，先排完最左边第一列，再排第二列；
- `B`：从下到上，先排完最左边第一列，再排第二列；

方向使用 AutoCAD 原生关键字选项，可在命令行点击选择，也可输入字母 `L/R/T/B`；直接回车默认从左到右。

## 编译与安装

需要 .NET 8 SDK。执行：

```powershell
.\build.ps1 -Configuration Release
```

构建结果位于 `dist\CadDrawingNumber.bundle`。将整个文件夹复制到：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\CadDrawingNumber.bundle
```

重启 AutoCAD 后插件会自动加载。也可以在 AutoCAD 中使用 `NETLOAD`，手动加载对应版本目录中的 `CadDrawingNumber.dll`。

- AutoCAD 2021-2024：使用 `Contents\2021-2024`；
- AutoCAD 2025 及以上：使用 `Contents\2025-Plus`。

### AutoCAD 2016

AutoCAD 2016 专用版使用官方 `20.1.0` API 和 .NET Framework 4.5 编译，不依赖 IFoxCAD 运行库。直接在 AutoCAD 2016 中执行 `NETLOAD`，加载：

```text
dist\AutoCAD2016\TYPC.dll
```

## 注意事项

- 块内的固定文字无法针对单个块实例独立改号，应使用块属性。
- 外部参照中的文字不会被修改。
- 锁定图层或只读对象会被跳过。
